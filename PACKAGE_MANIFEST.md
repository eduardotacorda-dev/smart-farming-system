# Package Manifest

This package is documentation and instruction infrastructure, not application source code.

## Included

- Root and nested agent instructions
- Product, architecture, coding, database, and API standards
- Automation, IoT, AI, security, testing, and observability guidance
- Git, migration/seed, deployment, and Agile processes
- CI documentation-presence check
- Agent task template
- MVP requirements and implementation plan

## Intentionally not included

- Application credentials
- Real API keys
- Production infrastructure secrets
- Vendor-specific hardware credentials
- Fake commands for packages not yet installed
- Full application source code

The package is designed to be copied into a repository root before application development begins.
