# Agile Process

Use Scrum-inspired two-week sprints: planning, development, testing, review, retrospective, and backlog refinement.

Prefer vertical slices—database, backend, frontend, tests, and documentation—over building the whole backend first.

Write stories as `As a [role], I want [capability], so that [benefit]`. Use Given/When/Then acceptance criteria where practical.

## Definition of Done

The requirement is satisfied; migration, backend, frontend, validation, authorization, tests, documentation where required, lint/type checks, and diff review are complete; and no critical known issue remains.
